# Фронтенд Traci

Фронтенд написан на обычных HTML, CSS и JavaScript. Для запуска Node.js не нужен: nginx раздаёт файлы браузеру и перенаправляет `/api/` на Go-бэкенд.

Из корня проекта:

```sh
make docker-up
```

Открой http://localhost:3000, зарегистрируйся и войди. Новый аккаунт получает роль пользователя. Фильмы в каталог добавляет администратор. Чтобы создать аккаунт администратора, выполни `make create-admin` из корня проекта и введи данные нового аккаунта. После этого войди через интерфейс.

Порт интерфейса задаёт `FRONTEND_PORT` (по умолчанию 3000). `BACKEND_URL` задаёт адрес бэкенда для nginx, по умолчанию `http://app:8080` внутри Compose. Браузер обращается к `/api` на том же адресе, с которого открыта страница.

## Как устроен код

- `index.html` — каркас страницы: шапка, основная область, окно редактирования и уведомления.
- `styles.css` — цвета, размеры, расположение элементов и адаптация под телефон.
- `src/app.js` — страницы, формы и обработчики кнопок. `loadPage` загружает списки, `submit` отправляет формы, `action` обрабатывает остальные действия.
- `src/api.js` — HTTP-запросы через `fetch`, JWT-сессия и сообщения об ошибках.
- `src/ui.js` — подписи жанров и статусов, форматирование и экранирование пользовательского текста.
- `nginx.conf.template` — раздача файлов и проксирование API. Адрес бэкенда подставляется из окружения при запуске контейнера.

Когда ты нажимаешь «В коллекцию», обработчик в `app.js` вызывает `api.request`. Он отправляет `POST /api/collection` с JWT. nginx убирает `/api` и передаёт запрос Go-серверу. Сервер записывает фильм в PostgreSQL и возвращает JSON. JavaScript показывает результат на странице.

JWT хранится в `sessionStorage` текущей вкладки: обновление страницы сохраняет вход, выход удаляет сессию. Сервер проверяет права на каждом запросе. Фронтенд узнаёт роль после входа запросом к `/users/{id}`: администратору возвращаются его данные, обычному пользователю — запрет доступа. Чтение JWT на клиенте нужно только для ID и срока сессии; оно не даёт прав доступа.

Фильмы показаны с графическими обложками из CSS: текущий API не содержит поля для постеров.

## Проверки

Для тестов нужен Node.js 22 или новее. Проверки API-клиента и формирования запросов запускаются без установки зависимостей:

```sh
make test-frontend
```

Проверка в настоящем Chromium требует работающего Compose. Из каталога `frontend`:

```sh
npm ci
npx playwright install chromium
npm run test:e2e
```

Тест создаёт отдельные аккаунты и фильм, создаёт тестового администратора командой бэкенда `create-admin` и удаляет созданные записи при завершении. Он проверяет регистрацию, вход, CRUD фильмов, коллекцию, блокировку и удаление пользователя, выход и мобильную раскладку. Существующие аккаунты и фильмы не меняются.

Для другого порта: `FRONTEND_URL=http://localhost:3001 npm run test:e2e`. Для другого файла окружения укажи `ENV_FILE` с абсолютным путём. Интерфейс и тест должны использовать одну и ту же базу из Compose.

Документация используемых инструментов: [шаблоны конфигурации официального образа nginx](https://github.com/nginx/docker-nginx/blob/master/entrypoint/20-envsubst-on-templates.sh), [проверки Playwright](https://playwright.dev/docs/test-assertions).
